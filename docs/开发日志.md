### 做了什么

  - `.gitignore`：忽略 `node_modules`、`dist` 等
- 确定依赖版本：
  - Electron `45.2.1`
  - electron-builder `26.18.0`

### 技术调研结论（重要，后续要用）

- **DeepSeek 模型**：当前应使用 `deepseek-flash`（老的 `deepseek-chat` 已于 2026-07-24 下线）。
  - 接口：`https://api.deepseek.com/chat/completions`，OpenAI 兼容。
  - 默认开启「思考模式」，做快速问答要显式传 `thinking: { type: "disabled" }`。
  - JSON 输出：`response_format: { type: "json_object" }`，提示词里必须出现 “json” 字样；有空返回 bug，需要检查并重试。
  - 价格（off-peak，每 100 万 token）：输入 $0.15，输出 $0.60。
- **语音合成（重要变化）**：
  - 微软 Edge / Azure 的中文音色里**没有北京话**。标准普通话本身以北京音为基准，但不是「京片子」。
  - 2026-10-13 微软把 Edge Read Aloud 的反爬 token 升到 v2，全球 edge-tts 系客户端集体 403；`msedge-tts` 2.1.1 虽在此后发布，但官方没明确说明已适配，上线前必须实测。
  - **阿里 Qwen3-TTS 有真正的北京话音色**：`Dylan（北京-晓东）`，男声，胡同少年感，可通过提示词加强儿化。价格约 ¥0.8/万字符。需要阿里云 DashScope 的 Key。
  - 结论：M3 时让用户在「免费但没北京味、可能不稳定」和「有真北京味、需阿里云 Key」之间做选择。
- **语音识别**：Electron 的 Web Speech API **不可用**（会报 network 错误），M6 必须用独立方案。候选：
  - 本地 `sherpa-onnx` + SenseVoice（免费、离线、约 230MB，安装复杂）
  - 腾讯云/讯飞（国内直连，需额外账号）
  - OpenAI `gpt-transcribe`（最省事，但国内需要代理和境外支付）
  - 结论：到 M6 再和用户确认，不提前引入依赖。

## 2026-11-02 · M2：接入 DeepSeek（已完成）

### 做了什么

- `src/ai.js`：调用 DeepSeek `deepseek-flash`
  - `response_format: json_object`，提示词里包含 "json"
  - `thinking: { type: "disabled" }`（DeepSeek 默认开启思考，会变慢）
  - 输出字段：original / beijing / pinyin / explanation / changes / examples
  - 结果缓存到 `userData/ai-cache.json`（最多 300 条）
  - 错误分类：401 Key 无效、402 余额不足、429 频繁、5xx 服务故障、超时/断网
- `src/config.js`：API Key 用 Electron `safeStorage` 加密后存在本机
- 主进程 IPC：`config:status` / `config:set-key` / `config:test-key` / `ai:translate`
- 界面：输入框、回答卡片、设置页（填 Key + 测试连接）、错误提示

### 踩到的坑：DeepSeek 401

- DeepSeek 控制台**只在创建 Key 时完整显示一次**，列表里是打码的；复制到掩码就会 401。
- 解决：新建一个 Key，在创建弹窗里立刻完整复制。
- 额外加固：自动去掉空格、引号、`Bearer` 前缀、全角字符、零宽字符；设置页显示识别到的 Key 长度/前后几位和原始错误，便于排查。

### 验证

- [x] 用户输入「西红柿怎么说」能拿到北京话 + 拼音 + 解释
- [x] Key 保存后重启仍有效（加密存储）

## 2026-11-02 · M3：朗读（第一版完成，音色待升级）

### 做了什么

- `src/tts.js`：接入 `msedge-tts`（微软 Edge 神经语音）
  - 默认音色 `zh-CN-XiaoxiaoNeural`
  - 内存缓存（最多 60 条），同一句话重复播放不再请求

  - 失败自动降级到 Windows `speechSynthesis`
- 界面：卡片增加「▶ 朗读」「🐢 慢速」，回答后自动朗读
- 光球：用 Web Audio `AnalyserNode` 读取真实语音波形，球体跟着声音起伏

### 验证

- [x] `scripts/tts-smoke.js` 实测 Edge TTS 可用（2026-10 的 403 故障已恢复）
- [x] 用户能听到朗读
- [ ] 音色不够「京腔」——用户反馈需要更地道的北京味

### 音色升级过程（重要）

1. 先试了**火山引擎「北京小爷」**（`zh_male_beijingxiaoye_moon_bigtts`）
   - 新版控制台只给 API Key，走 V3 接口 `X-Api-Key` + `X-Api-Resource-Id: seed-tts-1.0`
   - 调用返回 **45000030（资源未授权）**：该账号/项目没有开通 1.0 资源
   - 北京小爷属于 1.0，而新版控制台默认只开通 2.0；1.0 可能还要求企业实名，个人账号走不通
2. 改用**阿里千问 Qwen3-TTS**
   - 模型 `qwen3-tts-flash`，音色 `Dylan`（北京-晓东，真北京话男声）
   - 接口：`https://dashscope.aliyuncs.com/api/v1/services/aigc/multimodal-generation/generation`
   - 返回音频 URL（24 小时有效）或 base64，WAV 24kHz
   - 价格约 ¥0.8/万字符（汉字按 2 字符计）
   - 个人实名即可，不需要企业认证
3. 结果：**用户确认「可以了」**，京腔朗读跑通。

### 当前语音方案

- 主引擎：千问 `Dylan`（真京腔），Key 用 `safeStorage` 加密存储
- 兜底：千问失败时自动改用微软 Edge 语音，并在界面提示
- 慢速：千问不支持语速参数，改用播放器 `playbackRate = 0.85`（保持音高）
